# Plan 03 — Drawer + MainList integration

## Goal
Add `src/components/main-list/Drawer.tsx`: always-mounted left slide-in
panel + scrim with 240ms ease-out transform, Esc-to-close, focus management
(focus first row on open, return focus to hamburger on close), `inert` when
closed, `useSwipeClose` integration, and footer `Ustawienia` row.

Wire it into `MainList.tsx`: own `drawerOpen` state, compute open-todo
counts per category from existing `useTodos` consumer, pass `onOpenDrawer`
to `AppBar`, and render `<Drawer>` with refs for focus return.

`AppBar` gains a forwarded ref on the hamburger button so the drawer can
return focus to it on close.

    onClose: () => void;
