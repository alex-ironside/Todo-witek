# Plan 05 — `RemindersSheet` + `ReminderListItem` + MainList wiring + retire `ReminderEditor`

## Goal
Wire the bottom sheet end-to-end. `MainList` gains `remindersForId` state
(opened by the existing `Przypomnij` overflow item). The sheet shows the
reminder list with `wysłane` badges, lets the user add a new reminder via
the OS-native datetime picker (snapped to 15 min), and removes existing
ones. The legacy `ReminderEditor` component + its tests are deleted; its
`onOpenReminders` no-op default in `MainList` is replaced with an internal
state setter.

`RemindersSheet.tsx`:
```tsx
interface Props {
  todo: Todo | null;
  onClose: () => void;
}
```
- `useRepo()` for writes; renders `<Sheet open={!!todo} onClose={onClose}
  title={t.reminderSheetTitle}>`.
- Subtitle: `text-textDim text-sm` with the todo's title.

  className="sr-only" onChange={handleAdd} />`.
- Primary `Dodaj termin` button: full-width, `bg-accent text-accentInk

  inside a `try/catch` (showPicker may throw if not visible; fallback no-op).
- Secondary `Anuluj`: text button, `text-textDim h-12`.
- `handleAdd`: parse value → `Date.getTime()` → `snapToFifteen` →
  `repo.update(todo.id, { reminders: [...todo.reminders, { id:

  value to `''`. Bail if NaN or todo missing.
- `handleRemove(id)`: `repo.update(todo.id, { reminders:
  todo.reminders.filter(r => r.id !== id) })`.
- `newReminderId`: same crypto-or-fallback util as ReminderEditor (inline,
  not exported elsewhere — KISS).
