# Plan 02 — `formatReminderTime` Polish absolute formatter

## Goal
Add `src/utils/formatReminderTime.ts` — a pure function that formats a
timestamp as Polish absolute date+time for the reminders sheet list (e.g.
`"śr., 5 maj 14:30"`). Distinct from the existing relative
`formatRemindAt` in `dateUtils.ts` (which renders `"Dziś, 14:30"` for the
row badge); the sheet wants explicit dates so a user with three reminders
can disambiguate them at a glance.

## TDD

### Red — `src/utils/formatReminderTime.test.ts`
With `vi.useFakeTimers()` set to `2026-05-04T08:00` so locale month
abbreviations are stable:
- A future Wednesday at 14:30 returns a string containing `"14:30"`.
- The same call returns a string containing the day-of-month digit
  (`"5"` for `2026-05-05`).
- Returns Polish month abbreviation (lowercase `maj` for May) — assert
  `string.includes('maj')`.
- Returns a Polish weekday abbreviation prefix matching `/^(pon|wt|śr|czw|pt|sob|niedz|niedz\.|nd)/i`
  for known weekdays (lenient regex because Intl varies between Node versions).
- Pure: same input → same output (call twice, assert equal).

Run: `npm test -- --run src/utils/formatReminderTime.test.ts` → red.

### Green
```ts
const fmt = new Intl.DateTimeFormat('pl-PL', {
  weekday: 'short',
  day: 'numeric',
  month: 'short',
  hour: '2-digit',
  minute: '2-digit',
});
export const formatReminderTime = (ts: number): string =>
  fmt.format(new Date(ts));
```

### Refactor
Header comment documents the intentional coexistence with `formatRemindAt`:
that one is relative ("Dziś, …") for the row badge, this one is absolute
for the sheet list — they are *not* duplicates.
