# PLAN-01 — Auth primitives: AuthShell + Field + BackButton

## Scope

Three small, dumb presentational primitives used by every auth screen.

**New files:**
- `src/components/auth/AuthShell.tsx`
- `src/components/auth/AuthShell.test.tsx`
- `src/components/auth/Field.tsx`
- `src/components/auth/Field.test.tsx`
- `src/components/auth/BackButton.tsx`
- `src/components/auth/BackButton.test.tsx`

## Behavior

### `AuthShell`
- `min-h-screen bg-bg flex flex-col items-center justify-center p-6`.
- Renders the brand mark `Todo` (text-3xl, font-semibold, mb-8) above `children`.
- No props besides `children: ReactNode`.

### `Field`
- Props: `{ label: string; type: 'email' | 'password' | 'text'; value: string; onChange: (v: string) => void; autoComplete?: string; id?: string }`.
- Layout: `<label>` over an `<input>`.
- Input: `bg-bgRaised text-text rounded-field px-3 py-3 text-base w-full`.
- Label: `text-textDim text-sm mb-1 block`.
- Auto-generates an `id` if not provided so label `htmlFor` works.

### `BackButton`
- Props: `{ onClick: () => void; label: string }`.
- Inline chevron-left SVG + label text.
- `text-textDim w-11 h-11 flex items-center gap-1` for hit target.

## Tests

- AuthShell: renders brand `Todo` and arbitrary children.
- Field: renders label associated with input (getByLabelText); typing fires onChange with new value; respects `type` attribute; respects `autoComplete`.
- BackButton: renders label; click invokes onClick; aria-label set to label.

## Constraints

- Tailwind only.
- Strict TS, no `any`.
- No Firebase imports.
