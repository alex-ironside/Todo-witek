# Plan 04 — PushGroup + InstallGroup

## Goal
- `src/components/settings/PushGroup.tsx` — `Switch` bound to a `push`
  prop matching `PushState` shape. Status text Włączone / Wyłączone in
  `text-textDim`. Helper text under title. Hidden when status is
  `'unconfigured'` or `'unsupported'` or when `push` is `null` (local
  mode).
- `src/components/settings/InstallGroup.tsx` — clickable row that fires
  `onInstall`. Hidden when `canInstall === false` (advisor confirmed
  `usePwaInstall` already gates installed state via this flag).
