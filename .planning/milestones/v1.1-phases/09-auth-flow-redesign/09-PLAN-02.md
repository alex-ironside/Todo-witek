# PLAN-02 — LoginScreen

## Scope

The redesigned login form per spec sections 5.

**New files:**
- `src/components/auth/LoginScreen.tsx`
- `src/components/auth/LoginScreen.test.tsx`

## Props

```ts
interface Props {
  onForgot: () => void;
  onUseLocal: () => void;
}
```

## Behavior

- Renders inside an `AuthShell`.
- `<h1>` `t.loginTitle`, `<p>` `t.loginHint`, two `Field`s (email, password).
- Inline error `text-danger text-sm` slot beneath each field.
- Submit (`bg-accent text-accentInk rounded-field w-full py-3`) labelled `t.loginSubmit`.
- Below the form: two centered text buttons `t.loginForgot` (calls `onForgot`) and `t.loginUseLocal` (calls `onUseLocal`).

### Validation (on submit)
- Empty email → set inline error under email; do not call `login`.
- Empty password → set inline error under password; do not call `login`.
- Errors clear when the user types in the offending field.

### Submit
- Calls `login(email, password)` from `../../firebase/auth`.
- On rejection, set form-level error (under password slot or above submit) using `err instanceof Error ? err.message : 'Logowanie nie powiodło się'`.
- No busy state on the login button (per CONTEXT spec). Listed as human-verification item.

## i18n additions (in PLAN-04 we'll consolidate, but reference these now)

- `loginTitle` (already exists, value matches), `loginHint` (override existing — value differs), `loginEmail`, `loginPassword`, `loginSubmit` (already), `loginForgot`, `loginUseLocal`, `loginEmptyEmail`, `loginEmptyPassword`.

Note: `loginEmptyEmail` and `loginEmptyPassword` are not in CONTEXT's enumerated list — use Polish strings inline. We'll either add the keys in PLAN-04 or use the already-present `resetEmptyError`/`Podaj hasło`. **Decision:** introduce `authEmptyEmail: 'Podaj adres e-mail'` and `authEmptyPassword: 'Podaj hasło'` in PLAN-04's i18n change.

## Tests

Mock `../../firebase/auth` at module boundary (login).
- Renders title, hint, both fields, submit, forgot link, use-local link.
- Submit with empty email → shows email error, login not called.
- Submit with empty password (email filled) → shows password error, login not called.
- Successful submit → calls `login('a@b.com', 'pw')`.
- Rejection → shows error message text from rejection.
- Click `t.loginForgot` → calls `onForgot`.
- Click `t.loginUseLocal` → calls `onUseLocal`.
- Email error clears when user resumes typing email.
