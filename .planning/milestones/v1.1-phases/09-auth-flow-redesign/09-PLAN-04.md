## AuthRouter

### Props
```ts
interface Props {
  onUseLocal: () => void;
}
```

### Behavior
Local state: `mode: 'login' | 'reset' | 'reset-sent'`, default `'login'`.
- `login` → renders `LoginScreen` with `onForgot={() => setMode('reset')}` and `onUseLocal={onUseLocal}`.
- `reset` → renders `ResetPasswordScreen` with `onBack={() => setMode('login')}` and `onSent={() => setMode('reset-sent')}`.
- `reset-sent` → renders `ResetSentScreen` with `onBackToLogin={() => setMode('login')}`.

- Click `Wróć do logowania` → LoginScreen visible.
