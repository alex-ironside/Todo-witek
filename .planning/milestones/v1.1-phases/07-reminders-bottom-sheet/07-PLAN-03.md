# Plan 03 — `useDragToDismiss` vertical pointer hook

## Goal
Add `src/hooks/useDragToDismiss.ts` — a vertical mirror of
`useSwipeClose`. Tracks downward pointer drags initiated within the top
32px (drag-handle zone) of the panel and reports the live offset; closes
on >80px distance or >0.4 px/ms downward velocity. Ignores drags
originating on form controls so the datetime-local input keeps working.

## TDD

### Red — `src/hooks/useDragToDismiss.test.tsx`
Render a test harness component holding a panel `div` ref + the hook;
expose `dragY` to assertions via `data-drag-y`. Synthesize
`PointerEvent` instances on the panel.
- Initially `dragY === 0`.
- pointerdown at panel-relative `y = 10` (within handle zone), pointermove
  to `y = 50` → `dragY === 40`.
- Negative drag (upward) is clamped to 0.
- pointerup after distance > 80 with low velocity calls `onClose`.
- pointerup with high velocity (large dy in 1ms) calls `onClose` even when
  dy < 80.
- pointerup below threshold and below velocity does NOT call `onClose`.
- pointerdown originating below 32px from top is ignored (no drag, no close).
- pointerdown on a `<button>` inside the panel is ignored.
- When `enabled === false` no drag is tracked.

Run: `npm test -- --run src/hooks/useDragToDismiss.test.tsx` → red.

### Green
Mirror `useSwipeClose` with these deltas:
- Track `dragY` instead of `dragX`, clamped to `>= 0`.
- On pointerdown: read `e.clientY - panel.getBoundingClientRect().top`;
  bail out if `>= 32`. Bail out if `e.target.closest('button,input,a,select,textarea')`.
- On pointerup: `shouldClose = lastDy > 80 || velocity > 0.4`.
- Call `onClose()` after resetting `dragY`.

### Refactor
Co-locate the threshold constants (`HANDLE_ZONE_PX = 32`,
`CLOSE_DISTANCE_PX = 80`, `CLOSE_VELOCITY_PX_PER_MS = 0.4`) at the top of
the file with comments.
