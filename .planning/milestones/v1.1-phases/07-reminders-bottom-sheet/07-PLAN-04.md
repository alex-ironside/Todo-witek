# Plan 04 — generic `Sheet` bottom-sheet primitive

## Goal
Add `src/components/main-list/Sheet.tsx` — reusable bottom-sheet for the
reminders sheet (this phase) and Settings (Phase 8). Contracts:
- `<Sheet open onClose title>{children}</Sheet>`.
- Slides up `translate-y-full → 0` over 220ms ease-out; backdrop fades.
- Always mounted; `inert` when closed (matches Drawer pattern).
- Esc closes; backdrop click closes; drag-down closes (via
  `useDragToDismiss`).
- `role="dialog" aria-modal="true" aria-label={title}`.
- `motion-reduce:duration-0`.
- Focus moves into the sheet on open (first interactive child) and back to
  `document.activeElement` (or supplied `returnFocusRef`) on close — same
  pragmatic shape as Drawer; *no* Tab cycling trap (deviation from CONTEXT
  flagged for human verification).

- Esc keydown listener active while open.
- Focus: on open, focus first focusable child (or panel itself if none);
  on close, restore previous active element. Document this in a comment as
  the Drawer-parity pragmatic choice — true Tab trapping deferred.
