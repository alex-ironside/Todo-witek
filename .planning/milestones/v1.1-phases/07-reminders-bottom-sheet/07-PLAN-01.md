# Plan 01 — `snapToFifteen` pure utility

## Goal
Extract the 15-minute snap logic from `ReminderEditor.tsx` (line 29) into a
pure, exhaustively-tested helper at `src/utils/snapToFifteen.ts`. Preserves
the existing scheduler contract: every persisted reminder's `remindAt` is a
multiple of `FIFTEEN_MIN_MS`.

## TDD

### Red — `src/utils/snapToFifteen.test.ts`
- Exact 15-min boundary returns the same value (0, `FIFTEEN_MIN_MS`,
  `FIFTEEN_MIN_MS * 7`).
- A timestamp 7 min past a boundary rounds DOWN to that boundary (≤7.5 min).
- A timestamp 8 min past a boundary rounds UP to the next boundary
  (>7.5 min). Encodes `Math.round` half-up tie behavior.
- Exactly 7.5 min past rounds UP (`Math.round` rounds half-away-from-zero
  for positive — `7.5 → 8`).
- Negative timestamps (theoretical) snap correctly: `-1 → 0`,
  `-FIFTEEN_MIN_MS - 100 → -FIFTEEN_MIN_MS` (closest boundary).
- Real datetime case from existing ReminderEditor.test.tsx
  (`2026-05-01T10:08` snaps to `:15`; `2026-05-01T10:07` snaps to `:00`)
  reproduced as direct ms-level assertions.

Run: `npm test -- --run src/utils/snapToFifteen.test.ts` → red.

### Green
```ts
const FIFTEEN_MIN_MS = 15 * 60 * 1000;
export const snapToFifteen = (ts: number): number =>
  Math.round(ts / FIFTEEN_MIN_MS) * FIFTEEN_MIN_MS;
```

Export `FIFTEEN_MIN_MS` too for tests/callers that need it.
