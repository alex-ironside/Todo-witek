# Plan 01 — PopoverMenu (anchored, dismissible)

## Goal
Create `src/components/main-list/PopoverMenu.tsx` — an anchored popover that
renders a list of items provided by the parent. No items are hardcoded; the
parent owns the contents and ordering. Dismisses on backdrop click, Esc, or
when the anchor scrolls out of viewport.

## TDD

### Red — `src/components/main-list/PopoverMenu.test.tsx`
- renders nothing when `open` is false.
- renders an item per `items[]` entry with its `label`.
- clicking an item fires its `onClick` and DOES NOT auto-close (parent owns close — needed so the first `Usuń` tap can keep the menu open during the 2s confirm).
- danger items render with `text-danger` color class.
- pressing `Escape` calls `onClose`.
- clicking the backdrop calls `onClose` (without firing any item handler).
- positions the menu using the supplied `anchorRect` (assert inline `top`/`left` close to the rect's bottom-left + 4px gap, right-aligned to anchor's right edge).
- when the menu would overflow the viewport's right edge (anchor near right side), it clamps to the viewport with at least an 8px margin.

Run: `npm test -- --run src/components/main-list/PopoverMenu.test.tsx` → red.

### Green
Implement using `React.createPortal` to `document.body` so the popover escapes
any clipping ancestors. Backdrop is a fixed full-screen invisible div under
the menu (z-index 60, menu z-index 61). Esc handler attached on mount to
`document` and removed on unmount. Position computed once on mount from
`anchorRect`:

```ts
const top = anchorRect.bottom + 4;
const right = Math.max(8, window.innerWidth - anchorRect.right);
```

Use `right` (not `left`) so the menu visually right-aligns to the anchor.

```tsx
interface PopoverMenuItem {
  label: string;
  onClick: () => void;
  danger?: boolean;
}
interface PopoverMenuProps {
  open: boolean;
  anchorRect: DOMRect | null;
  items: PopoverMenuItem[];
  onClose: () => void;
}
```

When `open && anchorRect` is true, render the portal. Width: 200px. Items
each `h-11 px-3` (≥44pt). Background `bg-bgSheet`, border `border border-hairline`,
`rounded-field`, `shadow-sheet` (existing token). Each item button calls the item handler ONLY — no auto-close.
Backdrop click and Esc still call `onClose`.

### Refactor
Add a guard so clicking inside the menu does not bubble to the backdrop
