# Plan 05 — ReminderBadge, TodoRow, OpenTodoList

## Goal
Build three composing components under `src/components/main-list/`:
- `ReminderBadge.tsx` — bell + relative time of the nearest unfired reminder; renders nothing if `todo.reminders.length === 0`.
- `TodoRow.tsx` — round checkbox (button[role="checkbox"]), title, ••• overflow trigger, optional ReminderBadge below title.
- `OpenTodoList.tsx` — `DndContext` + `SortableContext` wrapping a list of TodoRow with PointerSensor activation `{ delay: 250, tolerance: 5 }`. Long-press anywhere on the row drags. Reorder writes via existing `repo.reorder(orderedIds)`.
