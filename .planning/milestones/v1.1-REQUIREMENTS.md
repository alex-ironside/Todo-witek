# Requirements — v1.1 Mobile Redesign (ARCHIVED)

> **Shipped:** 2026-05-04 · **Status:** ✅ All 31 requirements satisfied · See `.planning/milestones/v1.1-ROADMAP.md` for phase breakdown.

## Milestone v1.1 Mobile Redesign

Source spec: `redesign/design_handoff_todo_witek/README.md` (locked hifi). All
visual decisions — tokens, copy, spacing, motion — come from that file. These
requirements bind the existing functional features (categories, reminders,
push, offline-first Firestore, local mode) to the redesigned UI.

### Theme & Tokens (THEME)

- [x] **THEME-01**: App ships an OKLCH token system (bg, bgRaised, bgSheet,
      hairline, hairlineSoft, text, textDim, textMute, accentInk, danger)
      reachable as CSS variables and TS constants.
- [x] **THEME-02**: User can pick one of five accent colors (Bursztyn, Róż,
      Mięta, Fiolet, Błękit). Choice persists per user (Firestore when
      cloud, localStorage when local) and applies app-wide as `--accent`.
- [x] **THEME-03**: Typography scale, spacing scale, radii, and the single
      sheet/drawer shadow match the spec; no other shadows are used.

### Main List (LIST)

- [x] **LIST-01**: Top app bar shows hamburger (opens drawer), brand "Todo",
      and settings cog (opens settings). Hairline divider below.
- [x] **LIST-02**: Two segmented category tabs (Prywatne / Służbowe) with
      animated accent underline.
- [x] **LIST-03**: Add row: full-width input with placeholder
      `Co dziś robisz?`, primary `Dodaj` button. Enter or button submits;
      input retains focus and clears on success.
- [x] **LIST-04**: Each open todo row renders a round checkbox, title, and
      `• • •` overflow trigger; reminder badge (bell + relative time) shows
      below title when reminders exist.
- [x] **LIST-05**: Completed todos collapse into a `Wykonane (n)` section,
      collapsed by default, expandable to show strikethrough rows.
- [x] **LIST-06**: Empty state for active category shows `Brak zadań.` and
      `Dodaj pierwsze powyżej.` (no illustration).

### Drawer (DRAWER)

- [x] **DRAWER-01**: Hamburger opens a left drawer (~80% width) with scrim;
      tap-scrim or swipe-left dismisses.
- [x] **DRAWER-02**: Drawer header shows brand "Todo" + signed-in email (or
      `Tryb lokalny` when local). Section label `Kategorie`.
- [x] **DRAWER-03**: Two category rows (Prywatne / Służbowe) with active
      accent bar, raised background, and trailing open-todo count.
- [x] **DRAWER-04**: Drawer footer has `Ustawienia` row (cog) above a
      hairline; tapping opens the settings screen.

### Per-Row Actions (ROW)

- [x] **ROW-01**: `• • •` opens a sheet/popover with three items: `Edytuj`,
      `Przypomnij`, `Usuń`.
- [x] **ROW-02**: `Edytuj` switches the row to inline edit; `Zapisz` commits,
      blur or ESC cancels.
- [x] **ROW-03**: `Usuń` does a two-step inline confirm — first tap shows
      `Na pewno?` for 2s, second tap deletes. No modal.
- [x] **ROW-04**: `Przypomnij` opens the reminders bottom sheet for the row.

### Reminders Sheet (REM)

- [x] **REM-01**: Bottom sheet (24px top radius, drag handle) with title
      `Przypomnienia` and the todo title beneath in `--textDim`.
- [x] **REM-02**: Existing reminders list with bell + formatted date/time;
      fired reminders show `wysłane` pill badge.
- [x] **REM-03**: Empty state `Bez przypomnień.` when none.
- [x] **REM-04**: Primary `Dodaj termin` opens the OS-native date+time
      picker; submitting writes a new reminder snapped to 15-minute boundary
      (preserves existing scheduler contract).
- [x] **REM-05**: Secondary `Anuluj` closes the sheet.

### Settings (SET)

- [x] **SET-01**: Settings screen has a back chevron + title `Ustawienia`,
      grouped on `--bgRaised` cards.
- [x] **SET-02**: Account group: `Zalogowany jako` + email; `Wyloguj` text
      button in `--danger`.
- [x] **SET-03**: Wygląd group: `Kolor akcentu` row → 5-swatch picker; active
      swatch has accent ring.
- [x] **SET-04**: Przechowywanie group: segmented control `Lokalnie` /
      `Chmura` (wraps existing storage-mode hook).
- [x] **SET-05**: Powiadomienia push group: title `Powiadomienia push`,
      helper `Przypomnienia działają, gdy aplikacja jest zamknięta.`,
      switch with `Włączone` / `Wyłączone` status (wraps existing
      `usePushNotifications`).
- [x] **SET-06**: Install group: `Zainstaluj aplikację` row + helper +
      chevron, hidden when PWA already installed (wraps
      `usePwaInstall`).

### Auth (AUTH)

- [x] **AUTH-01**: Login screen renders brand mark, title `Zaloguj się`,
      hint `Bez publicznej rejestracji.`, email + password fields,
      primary `Zaloguj` button, and two text links: `Nie pamiętasz hasła?`
      and `Użyj trybu lokalnego`. Inline `--danger` error on empty fields.
- [x] **AUTH-02**: Reset password screen: back chevron, title
      `Resetuj hasło`, hint copy, single email field, primary
      `Wyślij link resetujący` (busy label `Wysyłanie…`); empty email shows
      `Podaj adres e-mail`.
- [x] **AUTH-03**: Reset-sent screen: title `Sprawdź skrzynkę`, body copy,
      secondary outlined `Wróć do logowania` button.

## Out of Scope (v1.1)

- Public sign-up flow — explicitly excluded by spec (`Bez publicznej rejestracji.`).
- Onboarding tour.
- Multi-device sync conflict UI.
- Sharing / collaboration.
- More than two categories.
- Compact / Airy density variants — ship `balanced` only (per spec
  "ship balanced unless told otherwise").
